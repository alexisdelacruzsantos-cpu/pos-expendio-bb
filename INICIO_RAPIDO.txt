# POS-EXPENDIO-BB - Inicio Rápido

## Entorno de desarrollo (Linux)

### Para iniciar el servidor
```bash
cd /home/alexis/POS-EXPENDIO-BB/server
source ../venv/bin/activate
python app.py
```

### Para detener el servidor
Presiona `Ctrl+C` en la terminal donde está corriendo (hace checkpoint del WAL y un respaldo final automático en `pos/backup/`).

### Acceder al sistema
- URL: http://localhost:5000
- Inicia sesión con tu usuario y contraseña (admin, cajero o supervisor).

## Producción en tienda (Windows 8.1/10/11)

### Instalación (una sola vez, como Administrador)

**Opción A - Automática (recomendada para Windows 8.1 sin Git/Python):**
1. Copia `server\instalar_vm.bat` y `server\instalar_vm.ps1` a una carpeta limpia y vacía del equipo (ej. `C:\POS`) **dentro del mismo VM**.
2. Haz doble clic en `instalar_vm.bat` con clic derecho > **"Ejecutar como administrador"**.
3. Te pedirá un GitHub **Personal Access Token** (Settings > Developer settings > Tokens, con lectura del repo privado). No es necesario instalar nada a mano: descarga Python 3.9.13 + Git 2.46.2, clona el repo, instala el venv y registra el arranque automático.

**Opción B - Manual:**
1. Instala Python (https://www.python.org/downloads/) marcando **"Add Python to PATH"** (en Windows 8.1 usa la 3.9.13).
2. Ejecuta `server\instalar_servidor.bat` con clic derecho > **"Ejecutar como administrador"**.

### Iniciar / detener manualmente
- **Iniciar:** doble clic en `server\start_pos.bat` (abre el navegador solo).
- **Detener:** cerrar la ventana o presionar `Ctrl+C` (hace checkpoint + respaldo final).

### Arranque automático
- Al instalar con `instalar_servidor.bat` queda registrado como tarea de Windows **"POS Expendio BB"** que arranca el servidor al iniciar sesión.
- Para quitarlo: `server\quitar_autoinicio.bat` (como Administrador).

### Notas de operación
- El servidor usa **waitress** (WSGI de producción, estable). Para forzar el servidor de desarrollo: `set WSGI=dev` antes de iniciar.
- URL por defecto: http://localhost:5000 (aplicar el mismo puerto en el firewall si se usará desde otras PCs).
- Logs: `pos\logs\servidor.log`. Respaldo automático al arrancar y cada 24 h: `pos\backup\`.
